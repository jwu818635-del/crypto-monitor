# 加密货币技术雷达

一个静态前端仪表盘，覆盖 26 个高流动性 USDT 现货交易对，并展示市场广度、价格热力图、相对强弱、日线 K 线和技术指标。

## 数据与刷新

- 页面首次打开时加载内置的审阅快照。
- 浏览器随后每 60 秒从 Binance 公开市场接口尝试刷新日线数据。
- 指标包括 MA20、MA50、RSI(14)、MACD、20 日支撑/阻力和成交额比。
- 技术信号仅供研究和风险管理，不构成投资建议。

## 本地运行

```bash
npm ci
npm run build
```

构建结果位于 `dist/index.html`。推送至 `main` 分支后，GitHub Actions 会自动部署该目录至 GitHub Pages。
